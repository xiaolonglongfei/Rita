PROMPT #23 — Remove exact review-count/threshold text from privacy placeholder

CONTEXT:
Prompt #21/#22 fixed the actual data leak (real scores no longer shown before 
3 reviews), but introduced a NEW leak of a different kind: the placeholder 
text now explicitly states the review count and the exact threshold, e.g. 
"1 review — scores visible after 3 reviews". This exposes:
  1. The exact number of reviews an instructor currently has (competitively 
     sensitive — reveals adoption/traction per instructor)
  2. The exact threshold number (3) used for the anonymity-protection 
     methodology — this is proprietary logic that should not be disclosed 
     publicly, to prevent competitors from copying the exact mechanism or 
     gaming it.

  "Reviews pending — collecting feedback to protect reviewer privacy"

  section for consistency)

  privacy protected" — no numbers, keep as is)

  without the threshold number is much lower risk, but check with product 
  owner — Feilong — before deciding to hide it or not)
- Search the whole codebase for any other place a literal "3" or the phrase 
  "after 3 reviews" / similar threshold-revealing string appears in
