---
name: Club outreach privacy and attribution
description: The club outreach records are private; public club pages are independent, not affiliated club websites.
---

The user identifies `public.club_outreach` as private. Its outreach/contact information must not be included in public club pages, browser payloads, or public APIs.

**Why:** The user separately created a public club directory and private outreach records; using the same database schema does not make both datasets public.

**How to apply:** Public club features must use only the directory and public coach information. Club pages are independent and not club-endorsed; do not introduce club logos or images. Preserve this distinction when extending outreach features.
